# Striker RNG

A web striker-building game: roll anime-style soccer players, steal one attribute from each, and build the ultimate striker across 10 picks.

- **Roll** players across six rarities (Common → Secret) with luck scaling and a pity counter.
- **Pick an Attribute**: Shooting, Speed, Dribbling, Passing, Physical, Defense, Vision, IQ, Ego, Weapon. Signature attributes give a character bonus; same-squad players give a squad bonus. Weapon resets your special skill.
- **One reroll per build** — spend it on the player or your squad.
- **Customize** a 3D blocky striker (hair, face, torso, arms, legs, kit, aura) with rare unlockables.
- **Progression**: XP, levels, luck, cosmetic/weapon rewards, milestone drops, saved builds (localStorage).

All characters are original designs.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build to dist/
npm run icons    # regenerate icon + thumbnail in public/
```
